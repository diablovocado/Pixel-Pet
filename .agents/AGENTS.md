# Pixel-Pet Project Rules

## Auto Commit & Push
After completing **every task or prompt** that modifies any file in this project:
1. Stage all changed files: `git add -A`
2. Commit with a descriptive message following the format: `type: short description`
   - Types: `feat`, `fix`, `chore`, `refactor`, `style`, `docs`
3. Push to origin main: `git push origin main`

Do this automatically without asking for confirmation unless there is a merge conflict or auth error.
