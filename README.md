# 🐾 Pixel Pet — Desktop Companion & Landing Page

A tiny pixel-art cat for macOS and Windows. She chases your cursor, reacts to typing, naps at the dock, and keeps you company on your desktop.

## 🌐 Live Landing Page
[https://diablovocado.github.io/Pixel-Pet/](https://diablovocado.github.io/Pixel-Pet/)

## 📦 Direct Standalone Mac App Download
[https://diablovocado.github.io/Pixel-Pet/Pixel-Pet-Mac.zip](https://diablovocado.github.io/Pixel-Pet/Pixel-Pet-Mac.zip)

## 🛠 Local Development

```sh
# Install dependencies
npm install --legacy-peer-deps

# Run web dev server
npm run dev

# Run desktop Electron cat app
npm start
```

## Built With
- React 19 & TypeScript
- Tailwind CSS v4
- TanStack Router & Start
- Electron
